# PAW HAVEN — Pet Depression Care Experience Platform

> **They Feel More Than They Can Tell.**  
> *Because Their Mental Health Matters Too.*

Website trình diễn startup học thuật phục vụ buổi pitching **Shark Tank Debate — Học phần Quản trị Marketing**:

- **PAW HAVEN:** Trang thương hiệu, sứ mệnh, 3 nhóm phương pháp hỗ trợ, quy trình 6 bước, bảng gói dịch vụ, chiến lược STP & 4P và Booking Demo.
- **PAW UNIVERSE:** Trung tâm chăm sóc 3D mặt cắt isometric gồm 6 phân khu tương tác kèm bản đồ 2D mượt trên di động.
- **PAW QUEST:** Story-based mini-game 4 cấp độ giáo dục người nuôi về quan sát hành vi và lựa chọn chăm sóc an toàn.
- **INVESTOR HUB:** Tóm tắt mô hình kinh doanh, khung TAM/SAM/SOM chờ xác minh, Financial Simulator tương tác thời gian thực và Đề xuất Đầu tư & Rủi ro.

## Cách bật GitHub Pages trực tiếp từ bộ file phẳng này

Toàn bộ các file trong repository này đã được đóng gói phẳng ở cùng một cấp thư mục gốc (`root`) kèm `HashRouter` và đường dẫn tương đối `./`:

1. Mở tab **Settings** của repository trên GitHub → chọn mục **Pages** ở cột bên trái.
2. Tại **Build and deployment** → **Source**, chọn **Deploy from a branch**.
3. Tại **Branch**, chọn nhánh `main` (hoặc `master`), thư mục `/ (root)` → bấm **Save**.
4. Đợi khoảng 30–60 giây, tải lại trang **Settings → Pages** để nhận đường link website chính thức.
